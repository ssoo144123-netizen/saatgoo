# ساعت‌گو (SaatGoo)

اپ اندروید اعلام صوتی ساعت به فارسی، با اعلام دوره‌ای و هشدار روزانه.

## امکانات
- اعلام دوره‌ای ساعت (هر ۵، ۱۵، ۳۰ دقیقه یا هر ساعت) با سرویس پیش‌زمینه
- اعلام دستی ساعت
- هشدار روزانه با صدای پیش‌فرض آلارم گوشی و اعلام ساعت
- بازیابی هشدار و اعلام بعد از ریبوت

## ساخت
۱. پروژه را با Android Studio (Hedgehog یا جدیدتر) باز کن.
۲. روی Run بزن یا `./gradlew assembleDebug` را اجرا کن.
۳. APK در `app/build/outputs/apk/debug/` ساخته می‌شود.

## نکات
- نیاز به minSdk 23 (Android 6.0) و targetSdk 34.
- برای صدای فارسی، موتور TTS گوشی باید بستهٔ فارسی داشته باشد (مثلاً Google Text-to-Speech).
- هشدار با `setAndAllowWhileIdle` زمان‌بندی می‌شود؛ ممکن است چند دقیقه دیرتر از زمان دقیق اجرا شود.
- این نسخه هنوز برای Doze و بهینه‌سازی باتری کامل نیست.

## صدا و پیام
- انتخاب صدای زن یا مرد (مرد: زیر و بمی پایین‌تر؛ اگر موتور TTS صدای فارسی با نام مرد/زن داشته باشد، همان انتخاب می‌شود).
- پیام شامل سلام مناسب ساعت (صبح/روز/عصر/شب بخیر)، روز و تاریخ شمسی و ساعت است.
- تاریخ شمسی با الگوریتم داخلی محاسبه می‌شود تا روی Android 6 هم کار کند.

## زبان فارسی هنگام اجرا
- اگر موتور TTS گوشی صدای فارسی نداشته باشد، اپ صفحه‌ی نصب داده‌ی صوتی را باز می‌کند.
- اگر آن صفحه باز نشد، از تنظیمات گوشی بخش Text-to-speech را باز کن و بسته‌ی فارسی را نصب کن (مثلاً Google Text-to-speech).

## صدای فارسی آفلاین (Piper / sherpa-onnx)
- فقط صدای مرد آفلاین است (مدل `amir`). صدای زن از TTS گوشی استفاده می‌کند.
- مدل‌ها در زمان build از release های sherpa-onnx دانلود و داخل `app/src/main/assets` قرار می‌گیرند (در workflow).
- مدل مرد: `vits-piper-fa_IR-amir-medium`.
- کتابخانه‌ی sherpa-onnx (v1.13.8) از release رسمی گرفته شده و از قبل داخل پروژه است: `app/src/main/java/com/k2fsa/sherpa/onnx/Tts.kt` و فایل‌های `.so` در زمان build از GitHub Actions دانلود می‌شوند (فایل‌ها داخل ریپو نیستند تا حجم بالا نرود).
- هر مدل حدود ۶۰ مگابایت است؛ APK بزرگ می‌شود.
