# ساعت‌گو (SaatGoo)

اپ اندروید اعلام صوتی ساعت به فارسی، با اعلام دوره‌ای و هشدار روزانه.

## امکانات
- اعلام دوره‌ای ساعت (هر ۵، ۱۵، ۳۰ دقیقه یا هر ساعت) با سرویس پیش‌زمینه
- اعلام دستی ساعت
- هشدار روزانه با صدای پیش‌فرض آلارم گوشی و اعلام ساعت
- بازیابی هشدار و اعلام بعد از ریبوت

## ساخت
۱. پروژه را با Android Studio (Hedgehog یا جدیدتر) باز کن.
۲. روی Run بزن یا `./gradlew assembleDebug` را اجرا کن.
۳. APK در `app/build/outputs/apk/debug/` ساخته می‌شود.

## نکات
- نیاز به minSdk 24 و targetSdk 34.
- برای صدای فارسی، موتور TTS گوشی باید بستهٔ فارسی داشته باشد (مثلاً Google Text-to-Speech).
- هشدار با `setAndAllowWhileIdle` زمان‌بندی می‌شود؛ ممکن است چند دقیقه دیرتر از زمان دقیق اجرا شود.
- این نسخه هنوز برای Doze و بهینه‌سازی باتری کامل نیست.
